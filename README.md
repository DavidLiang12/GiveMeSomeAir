# GiveMeSomeAir

Open `index.html` in a browser to use the direction spinner. No installation or build is needed.

- **Spin the wheel** randomly selects Up, Left, Right, Down, Rotate Left, or Rotate Right.
- **Rest Time** opens a break screen and pauses a spin in progress.
- **Back to the wheel** resumes play. Escape also closes the break screen.
- Press Space while the page background is focused to spin.

The page works on desktop and mobile and respects reduced-motion preferences.
